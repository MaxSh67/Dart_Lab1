## Ответы на вопросы:
**1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?**

В Dart тип переменной известен заранее, и компьютер проверяет его до запуска программы. В Python тип определяется только когда программа уже работает. Главное преимущество: ошибки с типами видно сразу, и программа не сломается в самый неподходящий момент.

**2. Что означает *String?* ? Чем отличается от *String* ?**

`String` — это обычная строка, которая точно не пустая, не `null`. `String?` — это строка, которая может быть пустой. Если у переменной стоит `?`, компьютер заставит проверить её перед использованием.

**3. Зачем в Dart *final*, если в Python можно просто договориться не менять переменную?**

`final` — это запрет на изменение переменной, встроенный в сам язык. Если попробовать изменить такую переменную, программа даже не запустится. В Python такой защиты нет.

**4. Чем именованный параметр *{required String name}* отличается от позиционного? Приведите пример вызова.**

Позиционный параметр передаётся по порядку: `greet('Артём')`. Именованный — с указанием имени: `greet(name: 'Артём')`. Слово `required` значит, что этот параметр обязательно нужно передать.
